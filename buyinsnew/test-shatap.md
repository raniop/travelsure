# הוראות בדיקה - מערכת השת"פים

## 1. בדיקת API Route ישירות

פתח בדפדפן או Postman:
- `http://localhost:3000/api/shatap?id=770`
- `http://localhost:3000/api/shatap?id=771`
- `http://localhost:3000/api/shatap?id=1283`

**תוצאה צפויה:**
```json
{
  "id": "770",
  "name": "Nira Lizra"
}
```

## 2. בדיקת הדף עם Query Parameters

פתח בדפדפן:
- `http://localhost:3000/?aff=770`
- `http://localhost:3000/?shatapId=771`
- `http://localhost:3000/?id=1283`

**תוצאה צפויה:**
- השם "Nira Lizra" (או שם השת"פ המתאים) אמור להופיע במקום "אופיר מיוחד 20" בחלק העליון של הדף

## 3. בדיקה ללא פרמטר

פתח בדפדפן:
- `http://localhost:3000/`

**תוצאה צפויה:**
- השם "אופיר מיוחד 20" יישאר (ערך דיפולטיבי)

## 4. בדיקת ID שלא קיים

פתח בדפדפן:
- `http://localhost:3000/?aff=99999`

**תוצאה צפויה:**
- השם "אופיר מיוחד 20" יישאר (כי השת"פ לא נמצא)

## 5. בדיקת שמות בעברית

נסה עם ID שיש לו שם בעברית:
- `http://localhost:3000/?aff=803` (רחל גולדהמר)
- `http://localhost:3000/?aff=805` (דוד נחלאל)

**תוצאה צפויה:**
- השם בעברית אמור להופיע בצורה תקינה (עם HTML entities מפוענחים)
